What Changed in v4 Scope corrections

Two permanent scope decisions were made and are now reflected everywhere in this schema — not deferred to a later phase, removed entirely.

1. No multi-tenancy, ever.
Removed the tenants table entirely. Removed the tenant_id column from all 11 tables that previously carried it (clients, staff_users, projects, components, quotes, invoices, bookings). This platform will only ever serve Enzo Interiors — there is no reserved field, no future migration path, and no SaaS-for-other-businesses ambition baked into this schema.
2. No payment gateway, ever.
Removed the /payments/create-intent endpoint and every Stripe reference. The invoices table keeps its status and paid_at fields, but they are updated exclusively through the Admin's manual "Mark Paid" action — never by a payment webhook. Clients pay Enzo through the business's own external means (bank transfer, card machine) outside the platform.
