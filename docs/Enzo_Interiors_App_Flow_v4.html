Enzo Interiors Platform — App Flow Document

Marketing Site · Client Portal · Admin CRM — Screen-by-screen navigation flows

Public Website Flow apps/web

The public site funnels a prospective client from discovery to a booked consultation.

flowchart TD A["Homepage"] --> B["Services"] A --> C["About"] A --> D["Contact"] A --> E["Booking Wizard"] B --> F["Service Detail Pages"] F --> G["Quote Calculator"] G --> H["Get a Free Quote Modal"] H --> I["Submit then Confirmation"] F --> J["Portfolio"] J --> K["Project Detail Lightbox"] D --> L["Contact Form Submit then Confirmation"] E --> E1["Step 1 Service Selection"] E1 --> E2["Step 2 Date Picker"] E2 --> E3["Step 3 Time Slot"] E3 --> E4["Step 4 Contact Details"] E4 --> E5["Step 5 Confirmation"] M["Any Unmatched Route"] --> N["404 Page"]
  • Quote flow triggers POST /quotes/estimate for a real-time price range.
  • Booking flow can be pre-filled from an accepted quote.
  • Every flow ends in a booked consultation or submitted quote request.

Client Portal Flow apps/portal · PWA

The portal is the ongoing hub for a client's project after signing.

flowchart TD A["Login or Signup"] --> B["Dashboard"] B --> C["My Projects"] C --> C1["Project Detail"] C1 --> C2{"Approve or Request Changes"} C2 -->|Approve| C3["Kanban Advances"] C2 -->|Request Changes| C4["Revision Notes to Admin"] B --> D["My Quotes"] D --> D1{"Accept Decline or Revise"} D1 -->|Accept| D2["Triggers Quote to Invoice"] B --> E["Messages"] B --> F["Documents"] B --> G["Invoices"] G --> G1["View Status - Paid Outstanding Overdue"] B --> H["Settings"]
StepScreenAction
1Login/SignupAuthenticate via /auth/portal/login
2DashboardBento overview routes to any module
3Project DetailApprove or Request Changes
4My QuotesAccept, Decline, or Revise
5MessagesReal-time WebSocket chat
6DocumentsFilter and download
7InvoicesView status only; Admin marks Paid manually

  • Design-approval loop is the critical path.
  • Offline mode shows cached shell with reconnecting state.
  • Invoice payment is informational/manual in this build — no payment gateway is integrated.

Admin / CRM Flow apps/admin

Operational core following the full client lifecycle.

flowchart TD A["Login"] --> B["Dashboard"] B --> C["Clients"] C --> C1["Client Detail"] B --> D["Bookings and Availability"] D --> D1["Calendar or Manual Booking"] B --> E["Quotes and Pricing"] E --> E1["Build Quote"] E1 --> E2["Send to Client"] E2 --> E3["Client Accepts"] E3 --> E4["Convert to Invoice"] E --> E5["Component Pricing Library"] B --> F["Projects Kanban"] F --> F1["Drag Stage Assign Designer Upload Files"] B --> G["Invoices"] G --> G1["Invoice Builder"] G1 --> G2["Send or Mark Paid Manually"] B --> H["Messages"] B --> I["Content Manager"] B --> J["Settings"]
  • Quote-to-Invoice handoff carries line items without re-entry.
  • RBAC gating scopes Designer/Installer access to assigned projects only.
  • Invoice status is updated manually by Admin (Mark Paid); no automated payment gateway is wired in this build.

Cross-App / Backend Flow apps/api

All three frontends share one backend across a single business transaction.

flowchart LR W["Web Quote Created"] --> P["Portal Client Accepts"] A2["Admin Quote Created"] --> P P --> AD["Admin Converts to Invoice"] AD --> PP["Portal Shows Invoice Status"] M1["Admin Inbox"] <--> WS["WebSocket Gateway"] WS <--> M2["Portal Chat"] L1["Portal Login"] --> J1["Client JWT"] L2["Admin Login"] --> J2["Staff JWT"]
  • Quote lifecycle spans web, portal, and admin in one transaction.
  • Auth separation issues role-scoped JWTs per app.
  • Single-tenant only — all data belongs to Enzo Interiors, with no account-switching logic in this build.

PWA Install and Offline Flow Portal + Admin

Authenticated apps add an install/offline layer; the public site does not.

flowchart TD A["Manifest and Service Worker Detected"] --> B{"Platform"} B -->|Android or Chrome| C["Automatic Install Prompt"] B -->|iOS Safari| D["Manual Add to Home Screen"] C --> E["Standalone App Launch"] D --> E F["New Deployment"] --> G["Service Worker autoUpdate"] G --> H["Latest Logic Loaded Automatically"]
  • Install flow differs by platform (Android vs iOS Safari).
  • Service worker auto-updates without manual reinstall.
